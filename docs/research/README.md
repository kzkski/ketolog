# 市場調査メモ（公開サマリー）

市場調査・事業戦略の**詳細レポート**は、公開リポジトリから分離したローカル専用ドキュメントへ移管した。
このディレクトリには、公開して問題ない要点のみを残す。

## 公開サマリー

- Ketolog は当面、記録体験とデータ品質の向上に集中する。
- 収益・提供モデルの詳細（対象顧客、価格、販売戦略など）は非公開ドキュメントで管理する。
- ベータ〜一般公開の実行条件は [docs/release/README.md](../release/README.md) を正とする。
