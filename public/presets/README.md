# Ketolog プリセット

アプリに読み込めるレストラン・メニューの JSON プリセット集です。ファイルは **リポジトリに同梱**され、デプロイ後 **`/presets/ファイル名.json`** として静的配信されます。

コンビニ系は **`convenience-keto.json`**（アプリ上の店名は **コンビニ**）1 本にまとめてあり、チェーン別は各メニュー行の **`group`**（セブンイレブン／ファミリーマート／ローソン）で区別します。

**`external-steak-keto.json`** はいきなりステーキ公式の栄養 PDF（2026-03-17 版基準）の一皿値をベースにした外食プリセットです。ファイル名は `external-yakiniku-keto.json` 等と同様にチェーン名を含めません。アプリ上の店名は **ステーキ（汎用）**。`group` は **150g / 200g / 300g / 400g** と **調味料** のみです。

ステーキ・ハンバーグ・コンボの多くは、**付け合わせのコーン・にんじん・ブロッコリーを食べない前提（＝肉のみに近い目安）**とし、次の推定量を **日本食品標準成分表（八訂増補）に近い代表値**で P/F/C 換算のうえ **一皿合計から差し引いています**（コーン粒ゆで 18g・にんじん根生 20g・ブロッコリーゆで 25g。店頭の盛り付けより単品トッピングは多めのため、この量は控えめ目の想定）。**ペースト等は PDF のまま含みます**。ブレードミート（マッシュポテト添え）は付け合わせが異なるため **PDF 一皿のまま**です。メモ先頭は **【肉のみ目安】**／**【付け野菜除外目安】**／**【PDFそのまま】**／**【調味料】**（詳細は Issue #11）。

## 使い方（アプリ内・推奨）

1. Ketolog を開く
2. レストランタブの **＋** → **プリセットから選ぶ**
3. 一覧から取り込みたいプリセットを選ぶ（ワンタップでインポート）

## 使い方（手元の JSON ファイルから）

1. 使いたい JSON ファイルを用意（このディレクトリから取得してもよい）
2. Ketolog を開く
3. レストランタブの **＋** → **JSONからインポート** → ファイルを選択

## JSONフォーマット

アプリの **⚙ → 全データをJSONでダウンロード** でエクスポートしたファイルも同じ形式で読み込めます。

新しいプリセットを作るには、アプリの ＋ → **テンプレート** からひな形をダウンロードしてください。
