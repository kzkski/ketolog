# Ketolog プリセット

アプリに読み込めるレストラン・メニューの JSON プリセット集です。ファイルは **リポジトリに同梱**され、デプロイ後 **`/presets/ファイル名.json`** として静的配信されます。

コンビニ系は **`convenience-keto.json`**（アプリ上の店名は **コンビニ**）1 本にまとめてあり、チェーン別は各メニュー行の **`group`**（セブンイレブン／ファミリーマート／ローソン／カップヌードルPRO／どん兵衛PRO など）で区別します。

**`external-steak-keto.json`** はいきなりステーキ公式の栄養 PDF（2026-03-17 版基準）の一皿値をベースにした外食プリセットです。ファイル名は `external-yakiniku-keto.json` 等と同様にチェーン名を含めません。アプリ上の店名は **ステーキ（汎用）**。

**`group` はグラム単位ではなく、グランドメニューに近い品目名**（例: **ワイルドステーキ**、**赤身！肩ロースステーキ**、**リブロースステーキ**、**特選ヒレステーキ**、**ヒレカットステーキ**、**ワイルドハンバーグ**、**ワイルドコンボ**、**乱切りカットステーキ**、**グリルチキンステーキ**、**調味料**）です。同一グループ内に複数 g の行が並びます。**ステーキ重など丼類は含みません**。

ステーキ・ハンバーグ・コンボ・チキンは、**付け合わせのコーン・にんじん・ブロッコリーを食べない前提（肉のみに近い目安）**とし、コーン粒ゆで 18g・にんじん根生 20g・ブロッコリーゆで 25g を **日本食品標準成分表（八訂増補に近い代表値）**で換算した P/F/C を **一皿合計から差し引き**ます（ペースト等は PDF のまま含む）。**PDF にない 450g 行**（リブ・特選ヒレ・ヒレカット・ワイルドハンバーグ）は、PDF 既存行の傾きから **外挿した推定**です。**ヒレカット**の 200〜450g は PDF に行がないため **特選ヒレ同 g 行を代用**（450g は特選ヒレと同じ外挿）。**ワイルドコンボ**は（1）100+150→PDF 250g 行、（2）100+100→180g と 250g 行の補間、（3）300+150→PDF 300g 行、と対応付け。メモ先頭は **【肉のみ目安】**／**【付け野菜除外目安】**／**【調味料】** など（詳細は Issue #11）。

## 使い方（アプリ内・推奨）

1. Ketolog を開く
2. レストランタブの **＋** → **プリセットから選ぶ**
3. 一覧から取り込みたいプリセットを選ぶ（ワンタップでインポート）

## 使い方（手元の JSON ファイルから）

1. 使いたい JSON ファイルを用意（このディレクトリから取得してもよい）
2. Ketolog を開く
3. レストランタブの **＋** → **JSONからインポート** → ファイルを選択

## JSONフォーマット

アプリの **⚙ → 全データをJSONでダウンロード** でエクスポートしたファイルも同じ形式で読み込めます。

新しいプリセットを作るには、アプリの ＋ → **テンプレート** からひな形をダウンロードしてください。
